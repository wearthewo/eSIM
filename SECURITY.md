# Security policy

## Reporting a vulnerability

Please report security vulnerabilities by email to **support@esimsheet.com**.

Please do not open public GitHub issues, pull requests or discussions for security
problems. A public report can put users at risk before a fix is out.

In your report, please include:

- a description of the problem and where it is (URL, route or file);
- the steps to reproduce it;
- what an attacker could do with it.

Never include real activation codes, real customer data or anyone's personal data. Use
synthetic data, such as the files in `tests/fixtures/`.

## Scope

- This repository.
- The hosted service at https://app.esimsheet.com.

Please do not run denial-of-service tests, send spam or test against other people's
accounts or data.
