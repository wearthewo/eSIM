eSIM PDF generator

Upload a CSV or XLSX file of eSIM activation codes (up to {{ max_rows }} rows, {{ max_upload_mb }} MB). Each row becomes a branded PDF with a QR code, and you download them as a ZIP file. Orders over {{ chunk_rows }} rows are generated in parts of {{ chunk_rows }} rows, one ZIP file per part.

Start from the template, which has every column and keeps long numbers such as ICCIDs as text: Download template (Excel)

Each ZIP file includes manifest.xlsx (row, ICCID, PDF file name). Add an optional email column to also get mailmerge.xlsx (email, customer name, plan, ICCID, PDF file name) for your own mail merge. This site never sends email.

Files are processed in memory and never stored. Nothing you upload is saved, logged or kept after the response is sent.
