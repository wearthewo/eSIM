What you get

PDFs and a manifest

Each ZIP file includes manifest.xlsx (row, ICCID, PDF file name). Add an optional email column to also get mailmerge.xlsx (email, customer name, plan, ICCID, PDF file name) for your own mail merge. This site never sends email.

Privacy

Files are processed in memory and never stored: your file is never written to disk, logged or saved in the database. While an order is downloading, its checked rows are kept only in the server's memory (never on disk or in the database), so the parts can be made without sending the file again. They are deleted as soon as the order is complete, and at the latest {{ cache_minutes | thousands }} minutes after they were last used. History keeps only the file name, counts and keyed fingerprints that recognise codes already used.
